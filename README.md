일반판과 _for_Good_Day 각인판이 함께 배포되어 있다. 두 패치는 같은 일본어 원본을 사용하며 결과 ROM은 서로 다르다.

새 게임에서 길드 사무소를 한 번 나갔다 들어오기 전 SELECT로 어디서나 저장을 사용하면 저장 화면에서 멈출 수 있다. 기존 안내에 따라 이 구간에서는 SELECT 저장을 피한다. START를 먼저 누른 채 SELECT를 누르면 치트 설정창이 열린다. 전체 자연 완주 검수 완료일은 미확정.

## 적용 방법

1. 압축을 푼 무수정 원본의 크기·MD5·CRC32 또는 SHA-256이 위 표와 일치하는지 확인합니다.
2. 아래 해당 패치를 원본에 **한 번만** 적용하고 결과를 별도 파일로 저장합니다.
3. 적용 후 결과 크기와 체크섬을 다음 표와 대조합니다.

xdelta3 사용 예시(모든 경로는 큰따옴표로 묶습니다):

```text
xdelta3 -d -s "7th Dragon (JP)(NRP).nds" "NDS 7th Dragon (Korean) v0.9.9A-wip271.xdelta" "NDS 7th Dragon (Korean) v0.9.9A-wip271.nds"
xdelta3 -d -s "7th Dragon (JP)(NRP).nds" "NDS 7th Dragon (Korean) v0.9.9A-wip271_for_Good_Day.xdelta" "NDS 7th Dragon (Korean) v0.9.9A-wip271_for_Good_Day.nds"
```

여러 패치가 있을 때는 사용할 변형이나 형식 **하나만** 선택합니다. 일반판과 _for_Good_Day 판은 같은 원본에서 서로 다른 결과를 만듭니다.

이미 한글화된 ROM에 덧씌우지 않습니다. 원본과 기존 저장 파일은 백업하고, 저장 호환성은 아래 기존 안내의 해당 버전 설명을 따릅니다. 버전이 다른 즉시저장 대신 게임 내 이어하기를 사용하세요.

로컬 WIP272 파일은 별도 후속 기록이다. 본 README와 체크섬은 현재 GitHub의 WIP271 두 배포판 기준이다.
